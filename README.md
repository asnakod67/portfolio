# Static Personal Portfolio Website

A clean, responsive static personal portfolio website built with HTML5 semantic elements, CSS3 (Flexbox & CSS Grid), and modern JavaScript.

## Features
- Fully responsive design (mobile-first navigation toggle)
- Semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Flexible layouts using Flexbox and CSS Grid
- Ready to deploy straight to GitHub Pages

## Deployment to GitHub Pages
1. Create a repository on GitHub (e.g., `portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` directly to the repository root.
3. In repository **Settings** -> **Pages**, set branch to `main` (or `master`) and folder to `/ (root)`.
4. Click **Save** and wait 1-2 minutes for your live site link.
